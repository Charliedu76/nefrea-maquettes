# Maquettes Néfréa

Propositions de refonte du site [Néfréa](https://nefrea-bougies.myshopify.com), bougies perlées et objets en jesmonite faits main.

Ce dépôt est publié avec GitHub Pages : chaque modification envoyée ici met le site de maquettes à jour automatiquement, à la même adresse.

- `index.html` : page d'entrée qui présente les maquettes
- `bordeaux/` : maquette 1, proche de l'identité actuelle
- `moderne/` : maquette 2, objets détourés qui flottent en perspective
- `img/` : photos de la boutique (et `img/detoure/` pour les objets détourés)
- `js/main.js`, `commun.css` : code commun aux maquettes

Ce sont des aperçus : le panier est simulé et la boutique Shopify n'est pas modifiée.
